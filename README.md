# AV1 - Desenvolvimento de Sistemas Web

Projeto desenvolvido utilizando:

## Tecnologias

### Backend
- Node.js
- Express
- Prisma ORM
- MySQL

### Frontend
- React
- Tailwind CSS
- Axios

---

## Funcionalidades

- Criar tarefas
- Listar tarefas
- Excluir tarefas
- Integração completa entre frontend e backend

---

## Estrutura do projeto

```bash
backend/
frontend/
```

---

## Como executar

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
